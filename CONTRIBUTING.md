# Contributing

Read the department charter and status before extending the pipeline. Preserve source identity, distinguish observations from capture facts, and keep all intake outputs noncanonical. Add meaningful manual regression tests for changed persistence or handoff behavior.

Run `python -m unittest discover -s tests -v`. Avoid adding hosted CI workflows without an explicit project decision. Do not commit private corpus contents, local output or credentials. Contributions to this software and its documentation use the repository's MIT License. Preserve copyright notices and identify any third-party material and its applicable terms.
