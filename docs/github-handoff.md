# GitHub hosting

Public repository: [nanogarden-org/BOBW](https://github.com/nanogarden-org/BOBW). Source version: **0.3.0**.

The owner created the public repository on 2026-09-06 and requested the same license as TurtleML. The v0.3 source release uses TurtleML's MIT License text and copyright notice, with Bronson-Technologies attribution in the documentation.

The repository contains implementation, tests, configuration, HTML guides, contracts, the component catalog, and supplied historical source snapshots. Private corpus contents and generated intake output are excluded. No automatic GitHub Actions workflows are included.

The source release is committed to `main`; this does not create a version tag or a separate GitHub Release. The browser guide is at `site/index.html` and can be opened from a downloaded checkout. GitHub Pages website deployment is separate and is not configured here.

The Bronson-Technologies portfolio remains the architecture hub; B.o.B.W. owns the independently versioned ingestion implementation. The component catalog links to this repository.
