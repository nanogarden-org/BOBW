# Changelog

## 0.2.0 — Ingestion Department

- Formalized B.o.B.W. as the Content-Factory's front-end Customs Agent and warehouse sorter.
- Added traveler-provenance records with source identity, capture context, processing lineage, review state, and proposed route.
- Added capture classes: project, tool, signal/news, phase change, and unclassified.
- Added warehouse routes: raw artifact, reusable material, active project, archive, waste, and quarantine.
- Added inventory mode for backlog directories, including visible JSONL event logging.
- Added explicit checksum-verified staging with no overwrite of different artifacts.
- Added Content-Factory integration, operations, purpose, what/why, role, and attribution documentation.
- Added browser-readable department page and YAML examples.
- Preserved v0.1 source-packet reference behavior.
