# Contributing

B.o.B.W. is attributed to Bronson-Technologies within nanogarden-org.

Changes should preserve these invariants:

1. Source material remains identifiable and hash-linked.
2. Derived or model-generated material is labeled as derivative.
3. Proposed routes are not canonical promotion decisions.
4. Different artifacts are never silently overwritten.
5. Rights, privacy, ambiguity, and human authority remain visible.

Run the tests before committing:

```bash
python -m unittest discover -s tests -v
```
