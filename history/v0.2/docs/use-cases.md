# Use cases

## Archive and OCR recovery

A scanned report becomes readable Markdown and addressable segments while retaining page-image references, coordinates, OCR confidence, and human corrections. This allows later reviewers to recover the visual evidence behind a text result.

## Multilingual evidence

A document can retain source language, transliteration, translation, and translator/model details as separate layers. A downstream model can select a language-specific view without mistaking the translation for the original.

## AI memory and agent coordination

Agents receive structured chunks with stable IDs, scope, status, and provenance. Human operators receive the equivalent readable account of what the agent used and why. This reduces the tendency for memory systems to turn inference into invented history.

## Research, books, and Content Factory inputs

B.o.B.W. converts raw material into candidate components without collapsing rights, source reliability, editorial judgement, and product-release permission into a single automation step.
